.. _docker:

############
Docker Image
############

eProsima no longer distributes a standalone Docker image of |ddsrecord|.

A complete Docker image containing the eProsima DDS tools is available as part of a Fast DDS Pro
subscription.
To obtain it, request a Fast DDS Pro license through the
`eProsima commercial support form <https://forms.eprosima.com/reach/form/CommercialSupportRequest/formperma/Ac8GwewD7PTDadQZIV92qDEzNFfMlJnYmA029mSJtJ8>`_.

Without a subscription, |eddsrecord| can still be installed from binaries or built from sources.
See :ref:`installation_manual_windows` or :ref:`installation_manual_linux` for the installation
instructions, and :ref:`developer_manual_installation_sources_linux` for the steps to build the
project from sources.
